# Coffee Heaven ☕️

A visually appealing and responsive landing page for a fictional coffee shop, **Coffee Heaven**.  
Built with **HTML5** and **CSS3**, it showcases a modern design with smooth animations, interactive sections, and a warm coffee-inspired theme.

---

## 🚀 Features
- Sticky navigation bar with smooth scrolling
- Hero section with background image and call-to-action button
- Menu section highlighting specialties (Espresso, Latte, Cold Brew)
- About section describing the café’s values
- Gallery section with hover effects and café vibes
- Contact form with styled inputs and validation
- Animated fade-in sections and hover transitions
- Responsive design for desktop and mobile

---

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox + Grid)
